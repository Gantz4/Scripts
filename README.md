## ⚙️ How to Install

1. **Download** the script from the link provided in the table above.
2. **Extract** the folder into your FiveM server's `resources` directory.
3. **Add** the resource to your `server.cfg`:
   ```
   ensure resource-name
   ```
4. **Restart** your server or use `refresh` + `start resource-name` in the server console.
5. Configure the script by editing its `config.lua` (if applicable).
