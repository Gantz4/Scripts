### TruckJob Level system and progress rank - Qbox/QB/ESX
> # gantz_TruckJob Level system and progress rank

## Overview

gantz_scripts is a FiveM script designed to enhance gameplay by allowing players to interact with NPCs to accept tow truck missions. The script automatically detects the framework being used (QBox, QBCore, ESX, or standalone) and integrates seamlessly with the game environment.

## Features

**NPC Interaction**: Players can interact with NPCs to accept missions.

**Random Delivery Locations**: Missions involve randomly selected delivery locations using Vector3 coordinates.

**Tow Truck Management**: Players can change the tow truck model and manage its functionalities.

**Dynamic Drop-off Points**: A visual circle is displayed on the ground for drop-off locations.

**Job Exit Option**: Players can exit the job at any time.

**Reward System**: Players earn XP and money rewards, compatible with QBox, QBCore, ESX, and dirty money.

**Fuel Management**: Integrated with ox_fuel for realistic fuel management.

**Database Integration**: All data is managed through a database for persistence.

**Multi-language Support**: Translations are provided in both English and Spanish.

## Installation

1. Download the gantz_scripts folder.

2. Place the folder in your FiveM resources directory.

3. Add `ensure gantz_truckjob` to your server configuration file (server.cfg).

4. Ensure that your server has the necessary dependencies installed (QBox, QBCore, ESX, ox_fuel).

## Usage

- Approach the designated NPC to initiate the mission acceptance process.

- Choose your desired tow truck model from the available options.

- Follow the mission prompts to complete deliveries and earn rewards.

- Use the exit option if you wish to leave the job at any time.

### AeroCorp - FiveM Script - Qbox/QB/ESX
># Gantz_AeroCorp - FiveM Script Documentation

Gantz_AeroCorp es un script avanzado para FiveM que implementa una empresa de transporte aéreo, permitiendo a los jugadores realizar misiones de transporte de mercancías y pasajeros, gestionar licencias de piloto y progresar en rangos para desbloquear aeronaves más grandes y misiones más lucrativas. Este script está diseñado para ser compatible con los frameworks **QBCore**, **ESX** y **Qbox**, utilizando las herramientas de Overextended (`ox_lib`, `ox_target`, `oxmysql`, `ox_inventory`) para garantizar un rendimiento óptimo, configuraciones personalizables y una experiencia inmersiva.

## Características Principales

**Sistema de Transporte Aéreo**:

   - Transporte de mercancías (items almacenados en `ox_inventory`) desde un aeropuerto a otro.

   - Transporte de pasajeros NPC entre aeropuertos, con interacciones dinámicas.

   - Misiones dinámicas con objetivos aleatorios (mercancías, pasajeros, rutas).

**Sistema de Licencias y Rangos**:

   - Los jugadores pueden obtener licencias de piloto a través de un NPC.

   - Progresión de rangos (Principiante, Intermedio, Avanzado, Élite) que desbloquean aeronaves más grandes y misiones más valiosas.

   - Requisitos de misiones completadas para subir de rango.

**Interacciones con NPCs**:

   - Dos NPCs principales: uno para gestionar misiones (en `vec4(-1247.53, -2693.33, 13.94, 144.66)`) y otro para licencias (en `vec4(-1229.3, -2709.55, 19.63, 158.23)`).

   - Uso de `ox_target` para interacciones con menús coloridos y animaciones.

   - Texto flotante sobre los NPCs para identificarlos (nombres configurables).

**Inventario y Recompensas**:

   - Uso de `ox_inventory` para gestionar mercancías (items) y verificar requisitos de misiones.

   - Recompensas en dinero (configurable: efectivo o cuenta bancaria) y experiencia de piloto.

**Configuración Flexible**:

   - Archivo `config.lua` con opciones para framework, moneda, modo debug, idiomas (español e inglés), y más.

   - Soporte para colores personalizados en menús (usando `ox_lib`).

**Eventos y Misiones**:

   - Eventos dinámicos para transporte de mercancías y pasajeros.

   - Sistema de fallos (penalizaciones por no completar misiones a tiempo).

   - Misiones especiales de alto riesgo con mayores recompensas.

**Características Profesionales Adicionales**:

   - Marcadores dinámicos en los aeropuertos para entrega de mercancías/pasajeros (usando `ox_target`).

   - Sistema de fatiga del piloto: los jugadores deben descansar tras varias misiones (configurable).

   - Registro de misiones en base de datos (`oxmysql`) para seguimiento de progreso.

## Requisitos

**Framework**: QBCore, ESX o Qbox.

**Dependencias**:

  - `ox_lib`: Para menús, alertas y utilidades generales.

  - `ox_target`: Para interacciones con NPCs y zonas.

  - `oxmysql`: Para gestión de base de datos.

  - `ox_inventory`: Para manejo de items y mercancías.

**Lua Version**: Lua 5.4.

**Node.js y pnpm**: Para compilar la interfaz de usuario (si se modifica).

**MariaDB**: Recomendado para mejor compatibilidad con `oxmysql`..
